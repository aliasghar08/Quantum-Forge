Architecture & Modular Licensing Boundaries

To respect copyleft licensing obligations and preserve modularity:

  • GFN2-xTB operates strictly as an independent microservice container over standard REST/CLI network boundaries.
  • Avogadro Bridge export scripts in avogadro_plugin/ are provided as open-source scripts adhering to GPL v2/v3 and communicate via decoupled JSON-RPC file passing.
  • MLIP Potentials (MACE, TorchANI/ANI-2x, CHGNet) are executed within separate Python workers.
