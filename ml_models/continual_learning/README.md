# Continual Learning Checkpoints & Replay Pipelines

This module preserves the autonomous continual learning trajectory of Quantum Forge, capturing fine-tuned checkpoints generated by the autonomous research harvester.

## Subdirectories

* **`checkpoints/`**: Houses `model_continual_latest.pt` and recent fine-tuned model checkpoints from literature ingestion cycles.
* **`pipelines/`**: Interfaces with the scholarly ledger (`data/autonomous_training/literature_ledger.sqlite`) and replay buffers (`continual_train.extxyz`, `continual_val.extxyz`).

## Continual Learning Specifications

* **Replay Buffer Strategy:** 80/20 train/validation zero-leakage split across historically extracted reaction coordinates.
* **Checkpoint Retention:** Rolling save with active pointer `model_continual_latest.pt` updated atomically after each validation loss threshold check.
